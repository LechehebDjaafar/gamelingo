# Code of Conduct

We want GameLingo to be welcoming to everyone, regardless of language, background, experience or identity.

**Expected:** respectful, constructive communication; credit others' work; assume good intent; accept feedback gracefully.

**Not acceptable:** harassment, insults, discrimination, personal attacks, doxxing, spam, or sharing pirated software or copyrighted game files.

Maintainers may remove comments, issues or contributions that violate this code and may ban repeat offenders. Report problems privately to the maintainers (see the repository's Security/Contact section).

This code is adapted in spirit from the Contributor Covenant (https://www.contributor-covenant.org).
