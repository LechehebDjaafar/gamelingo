# Unity (Mono and IL2CPP)

**Detect**: `<Game>_Data/` with `globalgamemanagers`, `UnityPlayer.dll`; `Managed/Assembly-CSharp.dll` (Mono) or `GameAssembly.dll` + `global-metadata.dat` (IL2CPP); `StreamingAssets/aa` (Addressables).

**Difficulty**: medium to hard — text is often inside compiled assets or localization packages.

## Where text hides
- Loose files: `StreamingAssets/**` (JSON, CSV, XML, txt) — easiest; use `strings_io.py`.
- Localization packages: Unity Localization (string tables in assets/Addressables), I2 Localization (language source in assets, often CSV-importable), custom tables.
- Hard-coded in scripts (`Assembly-CSharp.dll`) or TextMeshPro objects inside scenes/prefabs.

## Approaches (pick the least invasive)
1. **Runtime translation plugin** — BepInEx + XUnity.AutoTranslator style: hooks text at runtime, reads translation files you control (`Translation/<lang>/Text/_AutoGeneratedTranslations.txt`). Good when text is baked into assets; no asset repacking; works with Mono and IL2CPP builds (BepInEx 6 for IL2CPP). Translation files can be produced from your string table.
2. **Edit assets** — UABEA / AssetsTools.NET / UnityPy: export the TextAsset/MonoBehaviour containing the table, translate, import back to a *copy* of the `.assets`/bundle. Higher risk; asset hashes/CRC checks in Addressables can reject modified bundles.
3. **Add a language to an existing localization table** — when the game ships multiple languages, add one more column/locale and a selector entry.

## Fonts / RTL
TextMeshPro needs an SDF font asset containing the glyphs (generate with an Arabic font and the "Presentation Forms" ranges if pre-shaping), and a fallback font table. TextMeshPro does not shape Arabic natively in many setups: use an RTL plugin or `shape`/`visual` mode. With XUnity.AutoTranslator, set an override font in its config.

## Safety
IL2CPP + online anti-cheat/DRM games: stop. Keep the runtime-plugin route reversible by removing the BepInEx folder and `winhttp.dll`/`doorstop` files (the restore skill tracks them if you register them in the backup paths).
